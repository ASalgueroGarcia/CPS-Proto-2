# Data / Audio
AudioTuning: limits for runtime music pitch, music speed and SFX pitch, and the pause sound: the noise (clip, volume, fade) and how muffled and thin the music gets (pauseLowpassHz, pauseHighpassHz).
Sound lists go here too: Create > Audio > Sound Library, one per category.
