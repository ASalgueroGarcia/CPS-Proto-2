# Prefabs / Obstacles
Breakables, traps, hurting areas (BreakableObject, Explosives, HurtingArea, UnbreakableObject).
Pit: a 3 m shaft that blocks walking for player and enemies while projectiles pass over it; scale it to size. A layout with pits needs a Floor child (floor slabs around the holes, with PitFloor) so the hole shows. FallingScenery: a rock drops while its floor shadow grows to 1.5 m (FallingTrap script). Both are primitive placeholders.
