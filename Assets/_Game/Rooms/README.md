# Rooms
Room layout prefabs - the main thing level design produces.
Layout_001-010 = base layouts (Ana), built from the GDD's ACT 1 LAYOUTS drawings L01-L10 (50 x 30 m, 1 unit = 1 m). The drawing's lever wall is the door wall. Each layout has a SpawnPoints child that WaveManager uses. CombatScene_001/002 + ShopScene_001 = add-on layouts (Antonio).
Layout images: Art/Environment/Layouts. Spawning: Scripts/Waves.
Owner: Ana.
